\# CODSOFT Internship Tasks



This repository contains projects and tasks completed as part of my CODSOFT internship.



\## Tasks



\### 1. EduManage — Student Management System



EduManage is a web-based student management application built with Next.js, TypeScript, Prisma, and PostgreSQL.



\*\*Key features\*\*

\- Student and teacher management

\- Role-based access for administrators, teachers, and students

\- Teacher-class-section assignments

\- Attendance management

\- Examination and academic records

\- Fee management

\- Student portal



\*\*Technologies:\*\* Next.js, React, TypeScript, Prisma ORM, PostgreSQL, and Tailwind/CSS.
